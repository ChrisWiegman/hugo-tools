## 0.5.0 - 2026-11-12

### Breaking Changes

* Node.js 20 or later is now required; Node 18 is end-of-life. CI now runs the test suite on both Node 20 and the current LTS.

### Security Fixes

* Override minimatch to ^11.0.8 to resolve GHSA-g3hv-75wg-m249 (denial of service via globparts amplification) in the eslint dev dependency chain.
* Fixed pick-image on macOS passing the image path through a shell when copying it to the clipboard, which let a crafted filename run arbitrary commands.

### Features

* Added hugo- prefixed aliases for every command (hugo-draft, hugo-publish, ...) and switched the generated VS Code tasks to npx --no hugo-*, so npx can no longer fall back to unrelated npm packages named publish, draft, config, or vscode.
* import-books no longer re-queries Open Library and Google Books on every run for books that have no ASIN. Pass --refresh-asins to retry those lookups.
* Added a libraryFile setting for the page import-books updates after an import (default content/library.md). A missing library page is now skipped quietly instead of warning on every run, and import-books now reads .hugo-tools.json through the shared config loader, so it warns about invalid JSON like the other commands.
* import-books now converts Goodreads review HTML (line breaks, bold, italics) to Markdown so paragraph breaks survive Hugo's default HTML stripping.
* publish now accepts ./-prefixed and absolute draft paths, not just paths written relative to the site root.

### Bug Fixes

* Fixed import-books silently doing nothing when run through npx, a global install, or any path containing spaces.
* Fixed extract-tags dropping the last tag or category when the list ends the front matter, and added support for inline lists, single-value scalars, and CRLF line endings.
* Fixed vscode and extract-tags crashing on a site that has no posts directory yet.
* Fixed publish writing invalid YAML when a post title contains double quotes.
* Fixed publish later accepting impossible dates such as 2026-02-31.
* Fixed pick-image corrupting the images list when it is written inline (images: []) or as a scalar, and preserved existing indentation and CRLF line endings.
* Fixed the optional Amazon Product Advertising API ASIN lookup, which used GetItems with an ISBN (not a supported item ID type) and so never returned a result. It now uses SearchItems against the Books index.
* Fixed import-books overwriting a different book's file when a Goodreads title change renamed a book onto a path that was already taken. The book is now updated in place with a warning.
* import-books network requests now time out after 15 seconds instead of hanging the import indefinitely.
* Fixed import-books potentially rewriting lines in a book's review that look like front matter keys (title:, rating:, finished:, reference:, cover:).
* pick-image now files images under the year/month of the configured timezone, like the other commands, and can move images from a different drive.
* Fixed add-tags ending tag selection when a mistyped or out-of-range number was entered; it now asks again.

### Chores

* Update project dependencies.
* Fixed CI test runs on different branches cancelling each other, and corrected the lint workflow's job and step names.
* Corrected the README's note word threshold (350 words, not 200) and documented the new import-books review and rename behavior.
* Rewrote the README to cover every command, flag, and setting, use the hugo- prefixed command names throughout, and fix a package.json scripts example that used the reserved npm publish script name.
